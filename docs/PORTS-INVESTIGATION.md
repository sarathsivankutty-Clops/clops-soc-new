# Ports, Bindings, and Naming Investigation (`deploy/ports`)

Read-only inventory for making `docker-compose.yml` host ports configurable and conflict-free without breaking container-internal networking.

- **In-use / forbidden host ports:** `3000, 8000, 8001, 8003, 8081, 8086, 8088, 9090, 9092, 5432, 6379` (plus old stack internal ports `2181, 8087`).
- **Principle:** Change **host-side** ports only. Container-internal ports stay unchanged so internal DNS (`http://api:8000`, `kafka:29092`, etc.) keeps working. Only touch code/config where a host port, container/network name conflict, or verified mismatch requires it.

## 2. Container Names, Networks, and Volumes (`docker-compose.yml` & `docker-compose.prod.yml`)

### Container Names (`aisoc-*` -> remove / `name: clops-soc`)
All 35 services in `docker-compose.yml` declare `container_name: aisoc-*`:
`aisoc-postgres` (119), `aisoc-redis` (155), `aisoc-zookeeper` (171), `aisoc-kafka` (202), `aisoc-kafka-ui` (235), `aisoc-clickhouse` (251), `aisoc-opensearch` (276), `aisoc-qdrant` (325), `aisoc-neo4j` (347), `aisoc-api` (378), `aisoc-ingest` (602), `aisoc-enrichment` (686), `aisoc-fusion` (715), `aisoc-agents` (768), `aisoc-ollama` (910), `aisoc-ollama-pull` (958), `aisoc-litellm` (1057), `aisoc-osquery-tls` (1139), `aisoc-actions` (1219), `aisoc-connectors` (1265), `aisoc-threatintel` (1360), `aisoc-ueba` (1417), `aisoc-honeytokens` (1504), `aisoc-purple-team` (1563), `aisoc-realtime` (1613), `aisoc-slack-bot` (1646), `aisoc-teams-bot` (1696), `aisoc-escalations` (1751), `aisoc-mcp` (1777), `aisoc-web` (1806), `aisoc-prometheus` (1850), `aisoc-alertmanager` (1886), `aisoc-otel-collector` (1926), `aisoc-tempo` (1947), `aisoc-grafana` (1962).
And `docker-compose.prod.yml:78` declares `container_name: aisoc-preflight-secrets`.
- **Action:** Set top-level `name: clops-soc` in `docker-compose.yml`; remove `container_name:` across `docker-compose.yml` and `docker-compose.prod.yml` so Docker Compose generates `clops-soc-<service>-1` (matching `clops-soc-*` without `aisoc-*` collisions).

### Fixed Network Names (`docker-compose.yml`)
- `networks.aisoc` (`driver: bridge`, line 69) referenced on all 35 services -> **rename to `clops-soc`**.

### Fixed Volume Names (`docker-compose.yml:72-111`)
`escalation-state`, `tempo_data`, `postgres_data`, `redis_data`, `kafka_data`, `zookeeper_data`, `zookeeper_log`, `clickhouse_data`, `opensearch_data`, `qdrant_data`, `neo4j_data`, `neo4j_logs`, `ollama_data`, `aisoc_plugins`, `aisoc_plugin_keys`, `prometheus_data`, `grafana_data`, `alertmanager_data`.
- Top-level `name: clops-soc` prefixes all compose-managed volumes as `clops-soc_<vol>`, isolating storage; additionally rename `aisoc_plugins` -> `clops_soc_plugins` and `aisoc_plugin_keys` -> `clops_soc_plugin_keys` so no `aisoc_*` identifiers remain in volume declarations (verified `tests/test_persistent_state_volumes.py` checks container paths + declaration match, not literal names).
